# 首版规则与字段

2026-11-07整理。依据用户已确认规则及最新范围纠偏；本文替代旧产品草案、P0规则、分散决策和专项设计中的首版描述。标注“待确认”的内容仍是缺口，不由旧原型自动补齐。

## 1. 范围

深圳坪山区、个人开发、自营方向、Web首发；Vue 3＋TypeScript、Java/Spring Boot、PostgreSQL。先完成一个可运行版本，再持续完善。

首版提供两条独立路径：需求方注册登录、填写展示名后，可以直接邀请公开资料的老师；也可以发布需求，经审核公开后等待老师投递。两条路径均在对方接受后互选，再由双方分别授权联系方式；支持撤回。

首版不做：旧邮箱人工恢复、双人复核、邮箱换绑、完整身份纠错/跨身份归档、完整历史/争议管理后台、复杂资料核验/证件上传、完整聊天/通知中心、通用操作恢复平台、复杂权限/配置后台。预约、服务结果、合作、评价、支付/钱包、复杂推荐、多租户、原生App继续延期。必要的状态提示、基本权限、隐私保护和审核保留。

## 2. 身份与可见范围

| 使用者 | 核心能力 | 边界 |
| --- | --- | --- |
| 匿名 | 看审核通过、有效且允许公开的需求 | 保存、提交、投递、邀请、回应和授权须登录 |
| 需求方 | 本人资料、发布需求、查看老师、邀请和处理候选 | 包括成年本人、为未成年人发布的监护人；不提供学生独立账号 |
| 老师 | 本人资料、浏览需求、投递和回应邀请 | 必填资料补齐并主动公开后可投递/被邀请；资料不设人工审核、不标为已认证 |
| 运营 | 审核需求，通过或填写理由驳回 | 权限独立授予，不能在身份选择页取得；不能审核本人账号的需求 |

一个账号仅一种当前业务身份。身份选择有职责说明及确认，不提供角色切换器；纠错功能延期，不等于批准用户随意改身份或删除旧数据。本人和对方可读范围由服务端检查，不能只隐藏按钮。测试使用合成账号/资料。

## 3. 账号与本人资料

| 字段 | 必填与约束 | 可见性 |
| --- | --- | --- |
| 账号 | 4—16位英文字母/数字/下划线，字母开头；登录大小写不区分 | 登录及本人账号使用，不自动当公开展示名；既有长账号仍可登录 |
| 密码 | 8—64个Unicode码点；允许空格、粘贴；不强制字符组合，不trim/截断 | 注册与重置采用此范围；既有长密码仍可登录；不返回客户端，不进普通日志；安全散列存储 |
| 确认密码 | 注册/重置时核对，仅在表单中使用 | 不另存一份 |
| 邮箱 | 注册绑定并验证，一邮箱一账号；大小写视为同址，保留点号及“+”部分 | 私有，仅账号验证/找回，不自动分享 |
| 成年声明 | 主动勾选“我确认本人已年满18岁。”，不默认选中 | 私有，不收精确生日 |
| 业务身份 | 首次登录后确认需求方或老师一种 | 不包含运营角色 |
| 展示名 | 1—30码点，非空白；需求提交前只要求此项本人资料 | 通用资料；公开需求按批准版本展示，不联表带出新私有内容 |
| 手机号/微信 | 本人自主填写一种或两种，在分享时逐项选择 | 私有，只有授权成立才向本次关系对方展示；不作为注册/发布门槛 |

开放自行注册；邮箱验证成功不自动登录。正常忘记密码使用一次性邮件链接，重置成功撤销全部旧会话；邮件GET不消费凭据，明确提交才确认。跨浏览器验证缺少原注册上下文时，核对注册密码，防止激活他人预设密码的账号。找回回复不透露邮箱是否注册。链接失效、发信失败有清楚提示，不把“已受理”写成“已送达”。

当前资料只维护当前值；提交/投递所需的历史引用独立保存。未验证注册首次登记7天清理，重发不延期；未提交草稿最后成功保存90天清理、提前7天站内提醒。其余已确认的延期处理原则压缩记录于[延期规则摘要](archive/deferred-decisions.md)，不建设通用管理工作台作为开工前置。

## 4. 需求字段（已确认）

所有文字按Unicode码点计长；必填文字不能只有空白。草稿可不完整，已填写值仍需格式合法。金额用精确小数，页面单位固定人民币元/小时。

| 字段 | 控件方向 | 提交时要求与规则 |
| --- | --- | --- |
| 标题 title | 单行文本 | 必填，最多60码点 |
| 类别 categoryCode | 选项 | 必填；来自允许发布的类别组合，不接受任意文字 |
| 服务对象 audienceStageCode | 阶段选项 | 必填：小学/初中/高中/成年/其他 |
| 服务地点 locationText / 区域 districtCode | 小区或附近地标文本，区域按已开放范围记录 | 地点最多80码点，线下或方式待沟通时提交必填；线上可不填。当前区域为SZ_PINGSHAN（深圳坪山区），旧数据按既有坪山服务范围兼容。公开展示小区/地标，不填写楼栋、门牌、联系方式。既有areaCode街道记录继续兼容 |
| 年级 grade / 科目 subject | 随课外学习类别显示的文本建议输入 | 课外学习提交时必填，分别最多20/40码点；不收学校、班级 |
| 目标与现状 goal | 多行文本 | 必填，最多2000码点，不填儿童实名、学校班级、联系方式 |
| 服务方式 serviceMode | 可选线上/线下 | 可不填，表示留待沟通，不自动默认线下 |
| 预算下限/上限 budgetMin/Max | 两个金额输入 | 均必填且>0，最多两位小数，max≥min，可相同；没有999元业务上限 |
| 单次时长 durationHours | 常用1/1.5/2/2.5小时＋半小时调节/直接输入 | 默认2小时；提交必填，0.5—8小时，步长0.5小时 |
| 频率 frequency | 每周次数/可协商 | 必填，每周1—14次或可协商 |
| 可约时间 availabilityPreference / availableSlots | 可协商、偏好日期与上午/下午/晚上、可选精确时间 | 默认可协商；偏好模式提交时至少选一天，时段可不限，不生成虚假精确时刻。精确模式保留1—21项及既有同日不重叠规则；两种结构不能同时使用 |
| 时间备注 availabilityNote | 多行文本 | 可选，最多300码点 |
| 期望开始 expectedStartDate | 日期，可不选 | 可选；未填展示“时间可协商”；不得早于提交当天北京时间，不是预约 |
| 老师期待 tutorExpectations | 多行文本 | 可选，最多500码点 |
| 发布对象声明 publisherDeclaration | 主动勾选/选择 | 每次提交必填：成年本人/监护人为未成年人。小学初中高中仅后者，成年仅前者，其他二选一；私有，不进入公开响应 |

声明文案、六街道代码及类别方向见[发布选项](design/request-publishing-config-v0.1.md)。草稿预算可只填一端，提交前必须补齐；不存在的日期、无法表达的金额、非法时段不能静默修正后保存。接口序列化及技术容量在页面稳定后的接口整理中明确；原金额numeric(14,2)容量只是存储边界，不是业务指导价。

## 5. 需求流程与审核

三步：基本信息 → 时间预算 → 提交前预览。手动保存；下一步保存成功再跳转。离开未保存页提供继续编辑、保存后离开、放弃；失败保留输入，不误报成功。预览核对当前已保存内容，保存不等于提交。

| 状态 | 本人动作 | 公开与审核 |
| --- | --- | --- |
| 草稿 DRAFT | 保存、继续填写、预览、提交；从未提交过的草稿可确认删除 | 点击新建仅打开本地表单，首次主动保存才创建记录；首次保存校验失败不留下空草稿。不公开，不进入审核队列；修订草稿保留历史，不提供删除 |
| 待审核 PENDING_REVIEW | 只读查看进度 | 不公开；首版无待审直接编辑/撤回 |
| 已驳回 REJECTED | 查看理由，修改后重新提交 | 不公开；保留上次提交与反馈 |
| 招募中 OPEN | 查看需求、候选和撮合进度 | 仅审批通过、有效且准入允许时公开；当前范围无已公开编辑/暂停/关闭 |
| 已到期 EXPIRED | 查看，主动修订重提 | 不再公开，不新增投递/邀请；新提交重新审核 |

有效期：北京时间提交日期＋14天对应日结束；11月6日提交，11月21日00:00起到期。普通用户不输入或看到具体截止日期。草稿不启动有效期，审批不重置；待审到期不能批准，须本人主动新版本重提。审核耗时不自动改写期望开始日期。

运营按本次固定提交内容审核，通过或给出非空白驳回理由；不直接改写用户提交正文。重复点击、并发审核不能产生两次决定；版本变化时提示重读。通知故障不改变已提交审核结果。公开响应只发所需业务字段，不含联系方式、邮箱、精确地址、发布声明、具体截止日期和内部审核信息；自由文本也要审核并以纯文本安全展示。

## 6. 老师资料与撮合

### 6.1 老师最小资料（字段必填范围已确认）

以下字段及必填范围已由用户确认；填齐字段不自动公开，审核与公开/投递门槛见6.2。

| 字段 | 必填范围 | 填写与展示 |
| --- | --- | --- |
| 展示名 | 必填 | 沿用1—30个Unicode码点、非空白规则 |
| 服务类别 | 必填 | 从允许类别中选择一项或多项，不接受任意文字作为类别 |
| 服务方式 | 必填 | 线上、线下，可同时选择 |
| 服务区域 | 提供线下服务时必填 | 坪山区街道，可多选；仅线上可不填，不收精确住址 |
| 个人介绍 | 必填 | 简述能教什么、适合谁；教育与经验只作自述，不增加独立必填项或核验标识 |
| 报价 | 选填 | 人民币元/小时的报价区间；未填显示“面议” |
| 可服务时间 | 选填 | 简短文字说明；未填显示“时间可协商”，不建立排课表 |

报价、可服务时间不因选填而成为公开或投递的隐含必填项。不默认收证件或增加认证流程。

本轮按用户授权补齐以下首版表单设计：介绍1—1000个Unicode码点、不能仅空白；可服务时间最多300码点。报价两端均不填为“面议”；填写时上下限均须填写、均大于0、最多两位小数、上限不低于下限，可相同，无999元业务上限。未公开资料允许手动保存不完整内容，已填写值仍须合法；公开前统一检查必填项，错误定位到字段并保留输入。介绍及时间说明提示勿填手机号、微信、邮箱或精确住址，私密联系方式另行维护。

### 6.2 老师资料审核与公开/投递门槛（已确认）

- 首版不增加老师资料人工审核；资料标明为本人自述，不显示“已认证”，不将填齐资料视为资格核验。
- 补齐必填项后，由老师本人主动点击“公开资料”；此前仅本人可见，保存不自动公开。
- 公开后才能投递和被邀请；已登录的需求方可在老师列表及详情查看公开资料。老师发现列表及公开资料详情不向匿名开放。
- 手机号、微信仍为私密信息，不随老师资料公开；只有互选后按本次关系的双方授权规则分享。邮箱不在分享范围。

老师投递及关联需求的历史邀请仍须针对有效公开需求。需求方从老师广场发出的直接邀请无需先创建、提交或审核需求；老师资料仍须满足公开条件。

本轮设计默认：公开后修改使用“保存并更新公开资料”，提示会更新对外展示；须仍满足必填及格式要求，保存失败保留输入且不改线上内容。老师可确认“停止公开”，随后从发现列表移除，详情不再供新访客读取，不能新增投递/被邀请；已有关系不因此终结，双方仍可查看本次关系发起时的必要资料并回应、互选及管理联系方式。停止公开后可保存不完整资料，补齐并主动公开后恢复新增撮合。修改或重新公开不覆盖历史投递/邀请资料，不自动恢复或改变联系方式授权。

### 6.3 投递、邀请与联系方式

老师投递表达老师意向，需求方邀请表达需求方意向；待回应方本人接受后才互选。已有参与方之外的人无权读取或代操作。

直接邀请（2026-11-11用户明确修正）：选择老师 → 可选留言（最多500字）→ 发送邀请。仅需求方可发起，服务端核验展示名、老师身份与公开版本；不生成隐藏需求，不绕过公开帖审核。老师看到邀请人展示名、留言和当时老师资料，不展示邮箱或私密联系方式。直接邀请以需求方与老师为唯一组合；已有待回应或互选联系时返回已有进度，不自动接受。撤回后邀请人可重新发送，使用新轮次；直接邀请被拒绝后不能重复发送，老师端不提供重新发起直接邀请。以下按提交版本重发的规则只适用于关联需求的关系。

重复与相遇已确认：同一需求与同一老师只保留一条进行中的撮合关系。同一方重复点击展示已有进度，不创建第二条；收到对方意向后反向发起，引导查看并接受已有意向；双方同时发起，先成功的一方形成待回应，后一方查看已有意向并明确接受/拒绝，不自动互选。已互选再点击进入已有关系及联系方式授权进度。

| 当前进度 | 本人可做什么 | 结果 |
| --- | --- | --- |
| 等待对方回应 | 发起方查看或确认撤回 | 撤回后这次意向结束，不能再接受旧意向 |
| 等待我回应 | 接收方核对本次需求与老师资料，确认接受或拒绝 | 接受后互选；拒绝结束本次意向，不要求填写理由 |
| 已互选 | 双方查看进度、分别管理联系方式授权 | 不自动分享联系方式，不显示预约、合作或支付入口 |
| 已拒绝 | 查看结果；仅拒绝方可对同一提交版本主动重新发起 | 对方仍须明确接受；不能恢复上次接受或授权 |
| 已撤回 | 查看结果；需求仍有效且老师资料公开时可重新发起 | 新一轮意向须重新确认，不能复用旧回应；不另建并行进度 |

拒绝后的重发规则已由用户确认：被拒绝方不能对同一提交版本重发，拒绝方可改变主意主动发起。其余表中处理按本轮设计默认推进。重复、接受与撤回发生冲突时按最新结果展示：已撤回不能接受，已接受不能按待回应意向撤回，不用重试覆盖他人已完成的动作。联系方式撤回与意向撤回为不同操作。

本次关系保留发起时的需求提交内容和老师公开资料；资料更新提示查看最新公开资料，但不替换当时内容。需求到期主动重提不复制已有待回应/互选关系，仍进入原关系查看当时内容；已结束的意向可在新的有效公开提交版本下按新意向发起，不继承旧回应或授权。每轮只保留所需发起、回应及结束记录，不建设完整争议/归档工作台。

### 6.4 需求到期后的已有关系（本轮设计默认）

需求到期立即退出公开浏览，禁止针对该需求新增投递/邀请和重新发起；独立直接邀请不受需求审核或有效期影响。不依赖定时清理才生效。到期前已有待回应可继续查看当时资料并接受、拒绝或由发起方撤回，页面提示“需求已到期，不再接收新意向；本次已有意向仍可回应”。已有互选可继续双方授权、查看已允许分享的联系方式或撤回；到期本身不终结关系、不自动撤回授权。不得通过已有关系入口创建新意向或读取无关私有资料。

### 6.5 联系方式

2026-11-11体验调整：本人联系方式保存与站内离开确认使用居中的页面内弹窗，沿用浅底深绿配色，支持键盘取消与焦点返回。保存状态置于独立操作栏，与按钮分开；手机上下排列。未修改时禁用保存，取消不写入，失败保留输入。浏览器关闭/刷新时仍使用浏览器自身的未保存提示。

联系方式：互选后双方各自选择本次分享的手机号/微信并同意，只有双方有效同意后才能看到对方选中内容。任一方撤回停止后续平台访问，不能收回对方已知信息。已分享字段修改/删除使受影响关系停展示并双方重确认；未分享字段修改不影响无关授权。邮箱不在分享范围，不提供替对方授权/撤回操作。

首版输入设计：手机号支持中国大陆+86，输入11位数字且以1开头，地区明确显示为+86；其他地区提示暂不支持，不冒充号码归属或实名核验。微信号为1—64个非空白字符，不接受空格、换行或控制字符，不强制套用第三方账号注册规则；提示本人核对。这两项均选填，授权时至少选择一个本人当前有效填写的字段，不能选择空值；授权预览只展示本人将分享的内容，尚未双方同意时不返回对方值。

## 7. 当前设计状态与开放前事项
