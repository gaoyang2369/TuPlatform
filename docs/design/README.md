# 首版页面设计

以下设计轮记录对应2026-11-07；2026-11-08已开始账号/资料第一段真实代码开发，当前运行入口和验证边界见[交付计划](../tasks/mvp-delivery-plan-2026-11-07.md)。原Figma及此处只读预览本次未修改。

业务依据看[首版规格](../mvp-spec.md)，页面任务看[核心页面清单](page-inventory.md)。本轮已定向完善老师资料、发布控件、投递/邀请、回应互选和本人联系方式授权路径；人工恢复等延期页面不继续补齐。

## 设计与预览

- [原Figma及索引](https://www.figma.com/design/mIWvLoDcD6W0MlDny0ZwqB?node-id=9-309)：沿用同一文件和样式，不另建。
- [本地只读样例](interaction-preview.html)：默认评审首版核心路径，延期样例折叠为历史；表单只读/禁用，不执行保存、认证、邮件或跨账号动作。
- [节点索引](figma-state.json)：供后续定位原节点，不是开发清单。
- [发布选项与声明](request-publishing-config-v0.1.md)：供核心表单使用。

本轮读取并修改原Figma文件，保留本轮开始前的全部原画面根ID及既有看板。老师资料和撮合仍复用原页面及同源组件；新增画面是同一任务的必要步骤/状态，不等于新增路由。恢复、换绑、归档、预约等历史画面已标注延期，并从核心导航切断。

当前结构检查确认：核心入口不通向延期画面；老师不通向需求方本人操作；未勾选声明时无提交跳转；取消授权撤回返回原状态。核心画面由可编辑文本、控件实例和布局组成，没有完整UI截图充当页面。已内联检查老师表单、时间预算、老师详情、回应邀请、索引、发布声明及修正后的字段错误画面；中文沿用Noto Sans SC。证据在[当前检查记录](../../.tools/core-design-validation-2026-11-07.json)。

## 设计与真实实现的边界

原Figma已包含复选声明、类别/方式/街道复选、下拉选择、预算双输入、多行文本，以及保存/公开、发起/回应、授权/撤回的必要确认。页面设计可指导下一步接口与逐段实现，但固定跳转不证明真实校验、保存或跨账号同步已经发生。

字段校验、保存失败、无数据、会话失效、重复点击及版本冲突优先用同页状态表达。联系方式只在规则允许时进入响应和页面。老师视角的导航不能跳到需求方账号操作。

维护预览见[source说明](source/README.md)。本轮同步了当前场景源、主导航与只读HTML；现有Vue P0工程及旧演示ZIP未修改。完整浏览器播放、真实输入、手机软键盘及无障碍检查留待实现，不将历史截图或静态检查计为真实验收。
