## 主动声明

| 使用时点 | 文案/版本 | 约束 |

| 注册 | 我确认本人已年满18岁。 / adult-18-v1 | 主动勾选，不收精确生日 |
| 每次提交需求 | 我为已满18岁的本人发布本条需求。 / publisher-v1，SELF_ADULT | ADULT允许；小学/初中/高中拒绝 |
